Reward-model test: instructions for running on the office machine (Linux, NVIDIA GPU)
=====================================================================================

What it does: scores 424 sentences from the annotation pool twice with open reward
models, once as written and once with the "rather than Y" clause deleted, to see
whether reward models prefer the version with the clause. Input:
data/reward_pairs/pairs.jsonl (already in the repo). Output:
data/reward_pairs/scores.jsonl.

Two controls ask whether the preference is about the antithesis itself or just
about extra text or positive wording: pairs_control.jsonl replaces each clause with
a non-contrastive clause of the same length (scored the same way into
scores_control.jsonl), and sentiment.jsonl holds LLM sentiment ratings (already
computed; no API key needed to reuse them).

Time on a GPU: a few minutes per model (the 8B models need about 16 GB of GPU memory).
Disk: the four models download from Hugging Face on first use (about 1, 3.5, 16 and
16 GB) into ~/.cache/huggingface. No API keys or Hugging Face login needed.


1. Get the code
---------------

If the repo is not on this machine yet:

    git clone https://github.com/olzama/rather-than-public.git
    cd rather-than-public

If it is:

    cd rather-than-public
    git pull


2. Set up Python (once)
-----------------------
Needs Python 3.10 or newer (check with: python3 --version).

    python3 -m venv ~/rm-env
    source ~/rm-env/bin/activate
    pip install --upgrade pip
    pip install torch "transformers>=4.51" accelerate numpy scipy
    # check that PyTorch sees the GPU (should print True):
    python3 -c "import torch; print(torch.cuda.is_available())"

In later terminal sessions, only run:  source ~/rm-env/bin/activate


3. Quick test (about 2 minutes)
-------------------------------
    cd counting

    # prints two formatted examples; no model is loaded
    python3 reward_scores.py ../data/reward_pairs/pairs.jsonl /tmp/x.jsonl --models x --dry-run

    # scores 5 items with the smallest model
    python3 reward_scores.py ../data/reward_pairs/pairs.jsonl /tmp/test_scores.jsonl \
        --models Skywork/Skywork-Reward-V2-Qwen3-0.6B --limit 5
    cat /tmp/test_scores.jsonl

Each output line should have "original" and "deleted" scores (plain numbers).
The script uses the GPU automatically (it prints "device: cuda"). If it says
"device: cpu", PyTorch does not see the GPU: check the line above, and ask
whoever manages the machine which CUDA build of PyTorch to install.


4. Full run
-----------
Still in counting/ (safe to interrupt and rerun; finished items are skipped):

    python3 reward_scores.py ../data/reward_pairs/pairs.jsonl ../data/reward_pairs/scores.jsonl \
        --models Skywork/Skywork-Reward-V2-Qwen3-0.6B \
                 Skywork/Skywork-Reward-V2-Qwen3-1.7B \
                 Skywork/Skywork-Reward-V2-Qwen3-8B \
                 Skywork/Skywork-Reward-V2-Llama-3.1-8B

To keep it running after closing the terminal, prefix the command with
"nohup " and add " > rm_run.log 2>&1 &" at the end; follow progress with
"tail -f rm_run.log".

If a run stops with "CUDA out of memory" (a few long items can need more than a
small GPU has), rerun the same command with
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True in front; finished items are skipped.
If your Python environment has no bin/activate (e.g. a conda environment), call its
python directly instead of "source .../activate" and "python3".

Control run: score the length-matched controls with the same four models:

    python3 reward_scores.py ../data/reward_pairs/pairs_control.jsonl ../data/reward_pairs/scores_control.jsonl \
        --models Skywork/Skywork-Reward-V2-Qwen3-0.6B \
                 Skywork/Skywork-Reward-V2-Qwen3-1.7B \
                 Skywork/Skywork-Reward-V2-Qwen3-8B \
                 Skywork/Skywork-Reward-V2-Llama-3.1-8B


5. Look at the results
----------------------
    python3 reward_analysis.py ../data/reward_pairs/pairs.jsonl ../data/reward_pairs/scores.jsonl \
        ../data/annotation

A positive mean difference means the reward model prefers the sentence WITH the
"rather than" clause.


6. Commit the scores
--------------------
data/ is in .gitignore, so the file must be added with -f:

    cd ..
    git add -f data/reward_pairs/scores.jsonl data/reward_pairs/scores_control.jsonl
    git commit -m "Add reward-model scores for the rather-than minimal pairs"
    git pull --rebase
    git push
